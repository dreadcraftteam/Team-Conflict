Чтобы запустить сервер с использованием CoPlay нужно:

1. Запустить стандартный сервер через кнопку CREATE SERVER.
2. Написать в консоль команду sv_lan 0.
3. Написать в консоль команду changelevel [ИМЯ_КАРТЫ_НА_КОТОРОЙ_БЫЛ_ЗАПУЩЕН_СЕРВЕР].
4. Вписать в консоль эти команды:
	1. coplay_autoopen 1.
	2. coplay_joinfiler 2. (-1: Off, 0: Require random passcode, 1: Friends only, 2: Anyone)
	3. coplay_timeoutduration 5.
	4. coplay_portrange_begin 3600.
	5. coplay_portrange_end 3700.
	6. coplay_connectionthread_hz 300.
5. Написать в консоль команду coplay_invite.

После этого автоматически скопируется команда для подключения к вашему серверу.
