To start a server using P2P, you need to:

1. Launch the standard server via the "CREATE SERVER" button.
2. Write the command "sv_lan 0" to the console.
3. Write the command "changelevel [CARD_NAME of the SERVER THAT WAS STARTED]" to the console.
4. Enter these commands into the console:
	1. p2p_autoopen 1.
	2. p2p_joinfiler 2. (-1: Off, 0: Require random passcode, 1: Friends only, 2: Anyone)
	3. p2p_timeoutduration 5.
	4. p2p_portrange_begin 3600.
	5. p2p_portrange_end 3700.
	6. p2p_connectionthread_hz 300.
5. Write the command "p2p_invite" to the console.

After that, the command to connect to your server is automatically copied.
